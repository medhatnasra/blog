The auth system uses JWTs stored in HttpOnly cookies, so tokens stay out of reach of client-side JavaScript. Cookies also carry the Secure and SameSite flags, which lock them to HTTPS-only and block cross-site requests. Access tokens expire after a short window; a refresh token handles renewal automatically so users don't get kicked out. If something looks off, tokens can be revoked manually.
Built with the MERN stack, the API covers four main areas: auth (/api/register, /api/login, /api/logout, /api/refreshtoken, /api/auth/verify), user profiles, posts (CRUD + likes + images), and comments. MongoDB handles the data, Express and Node power the backend, and React sits on the frontend consuming the API. Admins get broader access on a few routes. Middleware includes helmet, cors, xss sanitization, and cookieParser. To run it: node index.js on port 4000, with a MongoDB URI and JWT_SECRET in .env
